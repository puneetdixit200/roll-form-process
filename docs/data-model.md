# Data model additions: Phase 18

The additive tables `recognition_evaluation_datasets`,
`recognition_evaluation_cases`, `recognition_label_assertions`,
`recognition_adjudications`, `recognition_threshold_profiles`,
`recognition_threshold_evaluations`, `confirmed_roller_design_usages`,
`roller_usage_promotions`, `roller_usage_relationship_snapshots`, and
`roller_usage_relationships` preserve review, dataset, promotion, and
relationship provenance. Existing Phase 15–17 tables remain authoritative for
their original records.
