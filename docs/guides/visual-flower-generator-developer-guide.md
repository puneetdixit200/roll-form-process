# Visual Flower Generator developer guide

The backend source of truth is split into `visual_profile_schema.py`,
`visual_profile_canonicalization.py`, `visual_profile_metrics.py`,
`visual_flower_engine.py`, `visual_flower_service.py`, and
`visual_flower_exports.py`. The React workspace is under
`frontend/src/features/visual-flower/`.

Set `ROLLFORM_FLOWER_PROTOTYPE_DATASET` to a local redacted `dataset.json`
generated by the existing private prototype ingestion command. Do not commit
that file or its source drawings. The API uses the configured dataset hash in
run provenance and returns no absolute source path.

Run:

```bash
rollform-extractor visual-profile-validate tests/fixtures/visual_profiles/open_channel.json
ROLLFORM_FLOWER_PROTOTYPE_DATASET=/private/dataset.json \
  rollform-extractor visual-flower-generate tests/fixtures/visual_profiles/open_channel.json \
  --stations 16 --candidate-limit 3 --output /tmp/visual-flower
```

Keep visual confidence explicitly non-calibrated. Changes to canonicalization,
metric weights, candidate generation, or dataset content must change the
algorithm/configuration hash and add deterministic tests.
