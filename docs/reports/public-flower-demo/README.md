# Public flower-sequence demonstration artifacts

This directory contains the public demonstration outputs requested for the
visual flower prototype. The images and generated candidate summaries are
published as user-approved demo data.

Contents:

- `flower-002/` contains the extracted sequence preview, overlay, and per-pass
  visualizations for the complete demonstration sequence.
- `flower-001/inspection/` contains the available public inspection visuals;
  this source did not produce a canonical accepted sequence in the inspected
  output, so it is not presented as one.
- `visual-candidates/` contains redacted generated candidate metadata,
  pass-level CSV evidence, SVG previews, and HTML snapshots.

These are visual prototype artifacts only. They do not establish production
manufacturing approval, physical roller availability, tooling compatibility,
or a tooling recommendation. Source DWG/DXF files, SQLite databases, model
registries, credentials, and local absolute paths are intentionally excluded.

The source files were audited before publication. Private source identifiers in
textual candidate evidence were changed to neutral `HISTORICAL-FLOWER-*`
labels; no source CAD or credential material is included here.
