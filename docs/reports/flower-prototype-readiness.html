Retrieval, alignment and generation

Retrieval uses available weighted shape, physical dimensions, developed-length, bend, and topology components. Variable-length historical sequences align monotonically with deterministic dynamic programming. Candidates are generated by bounded template adaptation in normalized geometry space, then validated forward against the target.

Every generated pass carries source flower/pass provenance and an explicit transformation. Station counts are bounded to 8–28. Low support and topology mismatch abstain.

Limitations and next data request

  • Only two complete flowers support this prototype; scores are not calibrated probabilities.
  • Generated geometry is a deterministic preview baseline, not a manufacturing design.
  • Units, thickness, material, machine limits, seam context and closed-profile semantics require engineer confirmation.
  • No roller asset assignment, tooling recommendation, forming approval, or manufacturability prediction is made.
  • Next step: 10–20 anonymized complete flowers covering multiple profile families, materials, thicknesses, station counts, and open/closed geometries.
