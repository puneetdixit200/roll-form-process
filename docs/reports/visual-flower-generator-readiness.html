Confidence definition

Visual confidence combines weighted visual metrics, evidence coverage, historical support, warning penalties, minimum/mean pass support and progression smoothness. It is an explainable prototype index and is not statistically calibrated.

Limitations and next data request

  • Only two historical flowers currently support matching.
  • Confidence is not calibrated and does not represent manufacturing probability.
  • Thickness, material, strip length, machine limits, springback and tooling compatibility are intentionally ignored in this visual mode.
  • Closed contours require a computational seam and compatible historical topology; otherwise the workflow abstains.
  • Request 10–20 anonymized complete flowers across profile families, station counts, and open/closed geometries before the remaining corpus.
